# AtCoder 成長記録

サマーインターンおよび本選考に向けて、アルゴリズムの基礎体力を鍛えるためのリポジトリです。
毎日1問以上を目標に、少しずつGeminiに今日の問題を指定してもらって解き進めています。
## 学習の進め方（自立支援ルール）

Geminiをテックリード役に仕立て、選考本番を見据えた以下の「縛りルール」で自学自習を行っています。

1. **コード提示の禁止**: 詰まっても最初の15分間は絶対に正解コードを見ず、日本語の論理構築から自力で行う。
2. **概念の言語化**: 実装前に「どのような手順・ロジックで解くか」を日本語でテックリードに説明し、レビューを受ける。
3. **エラーの自力解剖**: エラーが発生した際は、エラー文を自分で読み解き、修正案を自力でひねり出す。
4. **計算量と実務の結びつけ**: 正解した後に初めて、標準ライブラリ等を用いた「より合理的な書き方」や「時間計算量」を学び、実務（大量データ加工等）を意識したリファクタリングを行う。
